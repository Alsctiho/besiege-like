# BesiegeLike / 核心漫游

当前入口是 `scenes/core_journey.tscn`：玩家作为核心方块，在巨型高架遗迹中拾取零件、六面装配，通过钻岩、火球机关和旋翼推进打开新路线。旧机器拼装沙盒已移除，当前代码和验收仅围绕核心旅程。

## 操作与玩法

- 六面直接触发：左 `Q / ←`、右 `E / →`、上 `Space / ↑`、下 `↓`、前 `Z`、后 `X`；别名不重复触发。
- `W / S` 沿当前车头前进／倒车，`A / D` 向自身左／右打方向；转头后前后方向随车身改变，不是世界固定方向。空中轮胎只有空转，W/S不增加水平动力，A/D仍可调整朝向。飞行水平动力由旋翼、推进器等组件提供，惯性保留。
- `F` 拾取、`Tab` 组装、`V` 眺望、`F5 / F9` 保存与恢复；组装中右键拖动环视模型。
- 安装面决定按键，独立朝向决定作用；预览不更改实际装备，确认才提交，`Tab / Esc` 取消。重新打开保留上次选中的组件。
- 旋翼水平推力与工作朝向相反，朝上提供升力；每个动力组件在自身位置施力。左右反向推力可自转，同向对称推力直行，松开后角惯性逐渐衰减。
- 当前保持角色直立，只模拟偏航角运动，不模拟完整刚体侧翻。装配检查使用分部件形状与旋翼旋转扫掠圆盘，保留真实碰撞限制。
- 钻头先前伸并旋转，再破坏接触裂岩；裂岩崩解为翻滚碎块后清理。火球点燃桥头热能机关，伸缩杆接触白色开关，两者都可以升桥。
- `Esc` 菜单可继续或单次点击重新开始；重开会先备份原存档，再重置本关。游戏启动默认继续已保存的进度。

## 画面与声音

- 右上只显示少量悬浮图标键帽，保留常用键位相对关系；不绘制整键盘背景、空白键、方向键区或动力绿条。名称和用途仅在悬停提示中显示。
- 左上仅保留图标菜单，教学图示放在对应平台地面。
- 窗口按实际分辨率重绘，界面等比例缩放；组装预览随显示像素更新，使用 4× MSAA。
- 原创探索音乐循环播放，组件位置播放柔化机械音效；四轮接地声随速度变化，拾取、装配、崩解和升桥有事件音。
- `Esc` 菜单可分别调整音乐／音效音量。音乐在暂停和组装时降低音量，不重新开始。

## 运行与验收

用 Godot 4.7.2 打开 `project.godot`，按 F5 运行。默认使用 Forward+ / D3D12 和内置 Jolt Physics。

一键有声通关验收使用 `.codebuddy/skills/automate/besiege-self-verify/scripts/verify_capture.py`；先停止当前游戏，避免两个进程共用 MCP 请求目录。脚本检查真实操作、完整日志、音轨解码，并生成 MP4 与截图。自动通过之后仍需实际看图复核。

这是可玩原型；怪物掉落、完整战斗和长篇关卡尚未实现。
