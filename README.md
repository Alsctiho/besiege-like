# BesiegeLike 机器拼装沙盒

参考 Besiege 与《风之旅人》美术风格的开源 3D 机器拼装沙盒游戏：用方块、轮子、武器和喷射器自由拼装属于你的战争机器，然后驾驶它冲锋、开火、飞行、游泳。

![组件全家福](recordings/previews/new_palette_lineup.png)

## 技术栈

| 类别 | 技术 |
|---|---|
| 游戏引擎 | **Godot 4.7.2**（Forward+ 渲染器，D3D12） |
| 物理引擎 | **Jolt Physics**（Godot 内置模块：刚体簇、铰链关节、摩擦驱动） |
| 脚本语言 | **GDScript**（全部游戏逻辑，无第三方插件） |
| 自定义着色器 | **GDShader**（风之旅人风格渐变光照 / 沙地格线地形） |
| 3D 建模 | **Blender** 程序化建模 → glTF（.glb）导入，源文件随仓库提供 |
| 验收管线 | Godot Movie Maker 逐帧渲染 + ffmpeg 转码（确定性录像验收） |

## 功能特性

### 建造模式
- 0.5m 网格吸附拼装，幽灵预览（合法/非法提示）
- 组件：木/金属方块、马达轮、铰链、活塞、尖刺、火炮、火箭发射器、螺旋桨、浮筒、**喷射器**
- 六向旋转（含朝上/朝下）、按键绑定面板、撤销、JSON 存档

### 真物理模拟
- **刚体簇底盘**：互相连接的方块合并为单一复合刚体，稳定不散
- **真物理轮子**：铰链关节 + 关节马达，靠轮地摩擦力驱动，方向由轮子朝向决定
- **运动学执行器**：铰链臂（摆动武器）、活塞（伸缩矛）
- **喷射器**：长按喷射，尾焰粒子拖尾 + 火光
- 摩擦、重力、浮力（水域）、水阻尼全物理结算

### 武器与战斗
- 火炮（后坐力）、火箭（接触爆炸）、双联装默认配置
- **机器散架系统**：撞击 / 坠落 / 敌方攻击会让方块脱落，剩余部分继续工作
- **敌方 AI 机器**：保持距离游走、预判开火、**受击闪避**，可撞毁可击毁

### 关卡
- ⚔ **平原战场**：开阔竞技场 + 4 台敌方 AI 机器，消灭全部获胜
- ⛰ **解密关卡 · 飞上悬崖**：白色岩石峡谷，拼一架飞行器飞上方碑平台
- 🧪 沙盒测试场：靶塔 + 水池自由试验

### 美术
- **风之旅人风格渲染**：二段式渐变光照、暖棕暗部、金色边缘光、暖雾、辉光、ACES 调色
- 全部模型为 Blender 程序化低模（深胡桃木 + 铸铁 + 黄铜配色）

## 操作

| 按键 | 动作 |
|---|---|
| ↑ / ↓ | 轮子前进 / 后退（各机器按键可在建造模式修改） |
| 空格 / G | 开炮 / 发射火箭 |
| I / K | 螺旋桨升空 / 下降（长按 I 起飞前飞） |
| U / J | 喷射器（长按 U 喷射跃升，带尾焰） |
| A / D | 空中左右转向 |
| T | 返回建造模式 |
| 中键拖拽 / 滚轮 / C | 视角旋转 / 缩放 / 跟随切换 |

## 项目结构

```
├── scenes/            # 关卡与 UI 场景
│   ├── main_menu.tscn     # 主菜单
│   ├── garage.tscn        # 车库（选车 + 3D 预览）
│   ├── build_level.tscn   # 建造模式
│   ├── sim_level.tscn     # 沙盒测试场
│   ├── battle_level.tscn  # 平原战场
│   ├── puzzle_build/flight.tscn  # 解密关卡
├── scripts/
│   ├── core/          # 网格数据模型、装配器、组件数据库、存档
│   ├── blocks/        # 组件行为（轮/铰链/活塞/火炮/火箭/螺旋桨/喷射器）
│   ├── world/         # 水域、爆炸、敌方 AI、靶场、地形
│   ├── camera/        # 建造轨道相机 / 模拟跟随相机
│   └── ui/            # 建造 UI、HUD、车库、主菜单
├── shaders/           # Journey 风格着色器 + 沙地格线
├── assets/models/     # Blender 导出的组件模型（.glb）
├── tests/             # 物理标定与回归测试脚本
└── recordings/        # 验收视频（本地）+ Blender 源工程
```

## 运行

1. 安装 [Godot 4.7.2](https://godotengine.org/download)（标准版即可，无需 .NET）
2. 用 Godot 打开本目录的 `project.godot`
3. 按 F5 运行；或命令行：

```bash
Godot_v4.7.2-stable_win64.exe --path "D:/Godot/Godot Project/besiege-like"
```

## 开发说明

- 组件数据库在 `scripts/core/block_db.gd`：新增组件只需加一条定义 + 一个 .glb
- 物理装配在 `scripts/core/machine_assembler.gd`：刚体簇合并 / 关节创建规则见文件头注释
- `tests/` 内含关节轴向标定、摩擦、装配回归等物理测试脚本（`--script` 方式运行）
